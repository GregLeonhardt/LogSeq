## [[SyncThing]]
	- It is up and running with a couple small setups.
		- It works best if the owner on the TrueNAS side has the same permissions as the Docker application:
			- ``apps:builtin-user``
		- It will work (most of the time) as long as it has group permission but I have run into odd conditions where it will fail to sync.  All the problems I have seen so far are during the initial sync.  However it is probably best practice to just go ahead set the owner since all new files will be created with this owner anyhow.
