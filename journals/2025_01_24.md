# [[HomeLab]]
	- Starting to make some real progress on the migration from Synology to TrueNAS.
		- I had to make a slight modification to the method for backing up the TrueNAS home directories.  Initially I planed on just backing up all TrueNAS home directories to Synology.  Unfortunately that lead to a permissions problem on the TrueNAS side with system administrator users.  I could have given group permissions and made it all work but I didn't think that was the best way to go.  The option is still open but I decided to make an rsync job for all the users that need to be backed up.  After all the administrator users shouldn't be storing any real data in their home directory.
		- I discovered a mostly bad ethernet cable on the TrueNAS server.  The cable was working but only at 100Mb/s.  After replacing it the interface is running at 1,000Mb/s.  Much better.
