	- Here I am again without much progress.  In fact the progress has mostly been negative.
	- After the previous memory failure which caused weeks and weeks of delay I had another memory stick failure.  You would think that after all the time spent diagnosing the last one I would have been ready for this one.  But no.  After all how could a brand new memory stick fail again.  I ran the memory test to prove it was good when it arrived.  Well in the end another memory stick failed and this time it took out the entire ZFS storage pool.  There doubtlessly is (was) a procedure I could have used to recover the data but after a couple of days trying this and that I gave up and reformatted the HDDs.
	- The net result of all this was that all the work I did on the genealogy site and photos site and the family web site was all lost.
	- Sooooo.  The server has been running a couple of weeks on the only surviving memory stick and with all the messing around I finally came up with a migration strategy.
		- The Synology server will be completely demoted to a backup server.
		- I will build out a second TrueNAS server for the second backup server.
			- I am undecided as to which of the two backup servers will be moved externally.  I suppose this will eventually be decided by whichever one will be easier to run externally.
